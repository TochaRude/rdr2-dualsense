[size=5][b]DualSense for RDR2 (v2.0.1 — Community Edition)[/b][/size]

[size=4][b]Requirements & Install[/b][/size]
[list]
[*][url=https://www.nexusmods.com/reddeadredemption2/mods/1472]ScriptHookRDR2 V2[/url] (recommended) or classic Script Hook RDR2 + ASI loader ([b]dinput8.dll[/b] / [b]version.dll[/b])[/*]
[*][url=https://www.rdr2mods.com/downloads/rdr2/tools/76-lennys-mod-loader-rdr/]Lenny's Mod Loader (LML)[/url] for the pause-menu UI and PS icons (everything else works via [b]DualSenseRDR2.ini[/b] without LML)[/*]
[*][b]DualSense / DualSense Edge[/b] (USB or BT) — or [b]DualShock 4[/b] with the optional [i]DS4 Experimental[/i] download[/*]
[*][b]Important:[/b] Close DSX / DS4Windows, [b]Disable Steam Input[/b] for RDR2, and remove other DualSense or [b]startup_data.rpf[/b] icon mods[/*]
[*][b]Story Mode Only:[/b] Move mod files out before playing Red Dead Online[/*]
[/list]
Extract the zip directly into your main RDR2 folder (next to [b]RDR2.exe[/b]) — updating preserves [b]DualSenseRDR2.ini[/b]:
[code]DualSenseRDR2.asi
DualSenseRDR2\   (DualSenseCore.dll, weapons.json, haptics.json, translations.json, etc.)
lml\             (merges into lml\DualSenseRDR2 and lml\replace\...)[/code]
[i]Tip: Press [b]F9[/b] (or hold the PS button for 1s) to reload DualSenseRDR2.ini in-game; press [b]F10[/b] to inspect/edit the ground material under your feet.[/i]

--- CHANGELOG 2.0.1 (for Nexus file changelog box, concise) ---
- Clean controller LED shutoff in menus & on exit: lightbar, 5 Player LEDs, and the orange Mute LED now switch off automatically in menus (Main Menu, Pause Menu, Loading screens), leaving the DualSense dark when quitting RDR2 without needing any extra background process.
- Custom Lightbar colours & anti-pink tuning: added Idle Lightbar Colour presets directly in the in-game menu (Time of Day, Off [Events Only], White, Blue, Cyan, Green, Gold, Orange, Red, Purple) plus custom #RRGGBB / R,G,B support via [Lightbar] Color= in DualSenseRDR2.ini. Retuned the default Time-of-Day curve so daylight and twilight no longer drift pinkish.
- Full LED brightness & disable control: Lightbar Brightness now also dims the 5 Player LEDs below the touchpad (hardware High / Medium / Low), disabling the lightbar (Enabled=0) now suppresses confirmation flashes too, and [Lightbar] MuteLed=auto|on|off automatically turns off the orange Mute LED when the lightbar is disabled.
- Expanded Touchpad gestures: added dedicated shortcuts for Calm / Pat Horse / Crouch (L3), Eagle Eye (L3 + R3), Open Map, Open Satchel, Open Journal, Cinematic Camera, and Long Whistle across all 6 touchpad gestures (Click, Swipe Up/Down/Left/Right, Two-Finger Tap), with smoother swipe detection and click-swipe protection so clicking the touchpad never triggers an accidental swipe.
- Updated all 8 in-game UI languages (EN, DE, FR, ES, IT, PT, PL, RU) for the new Lightbar and Touchpad options.

--- CHANGELOG 2.0.0 (for Nexus file changelog box, concise) ---
First standalone Reworked release (continuing OldKrab's mod with permission):
- Expanded in-game DualSense menu to 63 options in 8 languages (EN/DE/FR/ES/IT/PT/PL/RU, English fallback) + global Trigger Strength slider (0-200%) + 6 Touchpad gestures
- Added Bow progressive draw, Dual-Trigger Lasso struggle, Fishing cast load, Fists/Melee triggers, Quick-Draw R2 tension, full-travel lever/bolt/pump cycling, and 93-weapon support
- Added Eagle Eye glow & chime, lit dynamite/fire-bottle fuse crackle & flicker, progressive gun cleaning, boat rowing & waves, spooked horses, wagon braking, mounting, herb plucking, body carrying, trains, hail/storms/thunder, and genuine RDR2 audio-based haptics/speaker sounds
- Added Player LED modes (Auto/Ammo/Health/Wanted police sweep), ScriptHookRDR2 V2 save-load stability, drift-free gyro calibration, and clean DualSense reset when exiting the game

--- AI DISCLOSURE ---
AI was used to create the Nexus Mods page banner/artwork, and AI coding assistance (Antigravity) was used to help write and refactor C++ code, JSON weapon/haptic configs, build scripts, multi-language UI translations (with native community review for Russian), and documentation/mod page text. All features and fixes were playtested in-game with a real DualSense controller and verified with automated tests. No AI-generated audio or in-game UI assets are used — all sound effects and PlayStation button icons come directly from RDR2's own game files.
